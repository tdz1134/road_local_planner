# rlp_common

公共基础层。定义整个系统共用的数据结构与几何工具函数，不含任何领域知识。

## 设计理念

路径规划系统涉及多个模块（道路建模、规划方法、ROS 节点），它们需要共享同一套基础类型（坐标点、栅格、路径、参数）。如果各模块各自定义，会导致类型不一致和循环依赖。`rlp_common` 将这些最底层的、无领域偏向的类型集中管理，作为整个依赖链的起点。

几何工具函数（折线操作）是道路建模和规划方法都会用到的原语，放在这里避免上层重复实现。

## 内容

### types.h

全局基础类型定义：

- **`Point2D`** — 二维坐标点（x, y），用于车体系下的所有几何计算
- **`GridMap`** — 局部占据栅格，车体系（x 向前，y 向左），支持 `occupiedAt()` / `valueAt()` 查询
- **`Path` / `PathPoint`** — 路径点列，每个点附带从起点到该点的累计弧长 s
- **`PlanMode`** — 规划模式枚举：`FOLLOW`（沿路走）/ `SEARCH`（朝终点推进）
- **`PlannerParams`** — 全部可调参数集中管理（车辆能力、规划、边界/走廊、模式仲裁、代价权重），与 `params.yaml` 一一对应

### geometry_util.h/.cpp

折线几何工具集，供道路层和规划层使用：

| 函数 | 功能 |
|------|------|
| `polylineLength` | 计算折线总弧长 |
| `resampleByArc` | 按弧长等距重采样（用于走廊中线均匀化） |
| `clipByArc` | 截断折线到指定弧长（用于前瞻裁剪） |
| `offsetPolyline` | 沿左法线横向偏移（用于生成走廊偏移族候选） |
| `pointToPolylineDistance` | 点到折线最短距离（用于越廊代价计算） |
| `toPath` | 点列转带弧长标记的 Path |

文件内部分为两个区域：匿名命名空间内的辅助函数（`pointSegDistance`、`lerp`，仅本文件使用）和公共接口（在头文件中声明）。
