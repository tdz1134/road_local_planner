# rlp_road

道路建模层。负责将感知给出的原始边界点转化为规划层可直接消费的走廊模型。

## 设计理念

感知模块给出的道路边界存在多种不确定性：可能只有一侧、可能短暂丢失、可能有误差。规划层不应该关心这些细节，它只需要一个"走廊"（中线 + 半宽 + 置信度）。`rlp_road` 的职责就是在感知和规划之间建立一层抽象：

1. **边界管理**：判定每侧边界是否有效（超时机制），维护路宽历史估计
2. **走廊构建**：根据边界可用性状态，选择不同策略构建走廊
3. **门面封装**：对外只暴露 `RoadModel` 一个类，内部细节对规划层不可见

这样规划层只需每周期调用 `road.update(boundaries, now)` 然后读取 `state()` 和 `corridor()`。

## 内容

### road_types.h

道路层公共类型：

- **`BoundarySet`** — 感知输出的左右边界点列（各约 20 个点，车体系，可能缺失）
- **`BoundaryState`** — 边界可用性状态枚举（见下方状态机）
- **`Corridor`** — 走廊模型：中线点列 + 半宽 + 状态 + 置信度 [0,1]。这是道路层对外的唯一产物

### boundary_manager.h/.cpp

边界数据管理器，核心职责：

- **有效性判定**：每侧边界独立维护时间戳，超过 `boundary_timeout`（默认 0.5s）判为失效
- **路宽估计**：双侧都有时，对左边界每个点找右边界最近点，取距离均值的一半，用 EMA 平滑
- **数据保持**：空的一侧不立即覆盖旧数据，由超时机制判定缺失

### corridor_builder.h/.cpp

走廊构建器，根据边界状态选择不同策略：

| 状态 | 策略 | 置信度 |
|------|------|--------|
| `BOTH` | 双侧重采样后逐点取中 | 1.0 |
| `LEFT_ONLY` / `RIGHT_ONLY` | 用历史路宽将已知侧平移半宽合成中线 | 0.6 |
| `MISSING_SHORT` | 沿用上一帧中线，半宽按 `corridor_inflate_rate × missing_age` 膨胀 | 0.3·e^(-age) |
| `MISSING_TIMEOUT` | 返回空走廊，上层退化处理 | 0 |

### road_model.h/.cpp

门面类，聚合 `BoundaryManager` + `CorridorBuilder`。规划层只与本类交互。

## 边界状态机

每侧边界独立超时，组合后产生 5 种状态：

```
        左有效 + 右有效
       ┌──────────────┐
       │     BOTH     │
       └──────┬───────┘
              │ 一侧超时
       ┌──────┴───────┐
       │ LEFT_ONLY    │ RIGHT_ONLY
       └──────┬───────┘
              │ 双侧超时但在记忆期内 (< corridor_hold_max)
       ┌──────┴───────┐
       │ MISSING_SHORT │  (沿用旧走廊，膨胀半宽，降置信度)
       └──────┬───────┘
              │ 超过记忆期
       ┌──────┴───────┐
       │MISSING_TIMEOUT│  (走廊不可信，上层退化)
       └──────────────┘
```
